# Third-party reference content

## wger exercise data and images

Source: https://wger.de/ — snapshot downloaded on 2026-10-11.

The exercise dataset and images retain the licence associated with each source entry. The bundled entries use Creative Commons Attribution ShareAlike 3.0, Creative Commons Attribution ShareAlike 4.0, or Creative Commons CC0, as recorded in `dist/exercise-sources.json`.

- CC BY-SA 3.0: https://creativecommons.org/licenses/by-sa/3.0/
- CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/
- CC0: https://creativecommons.org/publicdomain/zero/1.0/

Authors, source URLs, licences, and licence URLs are retained per exercise and image, including entries where the upstream author is recorded as wger contributors. Written HTML is converted to plain text for offline display. Images are resized to a maximum of 600 × 600 and converted to WebP; this change is included in each image credit. Adapted reference content retains the respective ShareAlike terms. It is distributed separately from Repclub’s original application code.

Repclub uses the data API snapshot, not wger’s application source code. No wger account or personal training data is involved in the importer.

## Fonts

DM Sans and Barlow Condensed are distributed under the SIL Open Font License 1.1. Their licence and copyright notices are included in `dist/fonts/OFL-dmsans.txt` and `dist/fonts/OFL-barlowcondensed.txt`. The local WOFF subsets have been renamed Repclub Sans and Repclub Display. These fonts are bundled so rendering does not contact a third-party font service.
